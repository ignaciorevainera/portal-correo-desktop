# Portal Correo Desktop 1.4.0

**Novedades de esta versión.**

## Los avisos ya no se cortan

Los mensajes que aparecen abajo a la derecha —cuando copiás un dato, cuando falla una conexión o cuando hay una actualización disponible— ahora se adaptan al ancho de la ventana. En ventanas angostas, o con la pantalla escalada al 125 % o 150 %, el texto se acomoda solo y el botón de acción baja a su propia línea en lugar de quedar apretado o cortado.

## Ajustes muestra el estado real al abrirlo

La sección de conexión ahora consulta el estado en el momento en que abrís Ajustes y lo muestra como **Verificando…**, **SQL Online** o **Modo Offline / Local**, con un botón **Reintentar conexión** para volver a probar sin cerrar el diálogo. Antes podía mostrar un resultado viejo de la sesión anterior.

También se quitaron de esa sección los datos técnicos internos (código de diagnóstico, origen y estado del archivo de arranque). El operador ya no necesita interpretarlos: si algo falla, la aplicación muestra el motivo en la pantalla de bloqueo.

## Un solo indicador de conexión

Se quitó el indicador de conexión que estaba duplicado en la barra superior. El estado se consulta en Ajustes, que es el único lugar donde además se puede reintentar.

## Qué se mantiene igual

- El instalador no contiene contraseñas y toma la configuración de la red al abrir.
- La aplicación funciona dentro de la red de Correo.
- No deja datos de acceso guardados en el equipo.

## Cómo actualizar

Si ya tenés instalada una versión anterior, la aplicación ofrece la actualización desde **Ajustes**. También podés descargar el instalador desde esta página e instalarlo encima: no hace falta desinstalar.

Si es la primera vez, descargá **Portal Correo Desktop Setup 1.4.0.exe**, ejecutalo y elegí **Más información → Ejecutar de todas formas** cuando Windows muestre la advertencia (el programa todavía no está firmado digitalmente).
